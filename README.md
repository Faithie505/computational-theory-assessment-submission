# computational-theory-assessment-submission
Submission for Computational Theory lab assessments

## Setting up the environment:
In order to access the submission, you must first clone the github repository. In the command line of the directory you want the project to be in, type in the following command:
git clone "https://github.com/Faithie505/computational-theory-assessment-submission.git"
This should copy all relecant folders and files into your current directory.

To download the necessray extentions, enter:
pip install -r requirements.txt

Lastly, to run the jupyter notebook exercise, type:
jupyter notebook problems.ipynb
